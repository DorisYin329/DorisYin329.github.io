01 / Overview

專題介紹

本專題透過多任務 BERT 模型， 同時分析中文文字中的情感傾向、細部情緒與對話行為， 並探索社群留言中較難辨識的反諷表達。

原始平台支援手動文字分析及 PTT CSV 留言分析， 透過 Flask API 呼叫模型並回傳分類結果。
